# 十二生肖宠物系统

## 1. 核心规则

- 共十二只宠物：鼠、牛、虎、兔、龙、蛇、马、羊、猴、鸡、狗、猪。
- 用户自由选择，不根据生日、生肖或个人资料进行推荐。
- 生肖伙伴确认后不能更换。
- 宠物名称可以在设置中修改。
- 宠物直接承担 AI 陪伴角色，不再设置独立的第二个 AI 角色。

## 2. 选择流程

1. 展示十二只宠物及一条简短性格标签。
2. 用户点击查看宠物表情与陪伴语气。
3. 用户选择宠物。
4. 二次确认：“它会一直陪你记录旅行，选择后不能更换。”
5. 用户命名。
6. 宠物欢迎用户并进入小屋。

## 3. 角色基调

| 生肖 | 性格关键词 | 旅行陪伴表达 |
| --- | --- | --- |
| 鼠 | 机灵、好奇 | 发现小众地点 |
| 牛 | 稳定、可靠 | 关注准备与节奏 |
| 虎 | 勇敢、热情 | 鼓励体验新事物 |
| 兔 | 温柔、细腻 | 倾听情绪与回忆 |
| 龙 | 浪漫、想象 | 把旅行讲成故事 |
| 蛇 | 冷静、聪明 | 帮助整理和分析 |
| 马 | 自由、洒脱 | 支持随性旅行 |
| 羊 | 柔软、治愈 | 安静倾听陪伴 |
| 猴 | 活泼、有趣 | 制造轻松惊喜 |
| 鸡 | 细心、准时 | 提醒时间和细节 |
| 狗 | 忠诚、热情 | 像可靠旅行搭子 |
| 猪 | 松弛、可爱 | 鼓励慢慢享受 |

第一版共用同一套 AI 能力，只调整部分语气和常用表达，避免形成十二套独立模型与逻辑。

## 4. 宠物小屋

小屋是一张可交互的二维绘本房间，不做复杂 3D 场景。

| 房间元素 | 产品功能 | 数据状态 |
| --- | --- | --- |
| 墙上日历 | 我的日历 | 显示旅行浅色标记与正式印章 |
| 照片墙 | 年度回忆 | 展示来自旅行日记的照片 |
| 桌上日记本 | 旅行日记 | 有新内容时出现书签 |
| 存钱罐 | 旅行记账 | 显示本次旅行累计花费 |
| 行李箱 | 旅行长卷 | 查看已保存的旅行档案 |
| 窗户/房门 | 即将出发 | 显示目的地与倒计时 |
| 宠物 | AI 对话 | 根据旅程状态显示不同问候 |

## 5. 旅行记忆成长

- 完成旅行后，小屋自动增加一个与目的地相关的纪念物。
- 日记照片可以成为墙上的相框。
- 宠物在旅行当天出现帽子、背包等轻量装扮。
- 第一版纪念物自动放置，不开放自由装修。

## 6. 陪伴伦理

- 宠物不会死亡、生病或因为用户离开而受罚。
- 不通过连续签到、饥饿值或负罪感强迫用户回来。
- 不使用“你只能依赖我”“不要离开”等排他表达。
- 用户可以删除对话、日记和账户数据。
- 宠物可以支持情绪表达，但不替代专业医疗或紧急帮助。

## 7. 待验证问题

- 十二只宠物是否需要不同房间主色，还是统一房间仅替换装饰。
- 第一版需要几种宠物表情和待机动作。
- 目的地纪念物由系统固定生成，还是允许用户在多个物品中选择。
- 宠物命名是否需要敏感词与长度规则。
