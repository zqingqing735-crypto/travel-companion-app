# 用户流程

## 1. 首次进入

```mermaid
flowchart TD
    A[首次打开 App] --> B[浏览十二生肖宠物]
    B --> C[自由选择宠物]
    C --> D{确认永久伙伴?}
    D -->|再看看| B
    D -->|确认| E[为宠物命名]
    E --> F[进入宠物小屋]
```

规则：不读取生日，不推荐“用户所属生肖”；生肖伙伴不能更换，宠物名字可以修改。

## 2. 核心导航

```mermaid
flowchart LR
    A[便签] --- B[旅行]
    B --- C[宠物小屋]
```

- **便签**：记录旅行灵感和随手想法。
- **旅行**：创建时间线计划并生成旅行长卷。
- **宠物小屋**：进入日记、日历、记账、回忆和 AI 对话。

## 3. 创建旅行

```mermaid
flowchart TD
    A[点击新建旅行] --> B[进入每日计划]
    B --> C[编辑旅行名称]
    C --> D[横向选择日期]
    D --> E[选择半小时时间段]
    E --> F[输入文字或 Emoji]
    F --> G{继续填写其他日期?}
    G -->|是| D
    G -->|否| H[播放出纸动画]
    H --> I[生成一日或多日旅行长卷]
    I --> J[保存至旅行档案与日历]
```

## 4. 日历状态

```mermaid
stateDiagram-v2
    [*] --> 无标记
    无标记 --> 浅色标记: 创建未来旅行
    浅色标记 --> 正式印章: 到达出行当天
    浅色标记 --> 无标记: 取消旅行
    正式印章 --> 旅行档案: 点击日期
```

旅行档案内展示旅行长卷、当天日记和当天花费。

## 5. 宠物小屋入口映射

| 物品 | 点击结果 |
| --- | --- |
| 桌上的日记本 | 进入旅行日记 |
| 墙上的盖章日历 | 进入我的日历 |
| 桌上的存钱罐 | 进入旅行记账 |
| 墙上的照片 | 进入年度回忆 |
| 宠物 | 进入 AI 对话 |
| 行李箱 | 选择旅行并查看旅行长卷 |
| 窗户或门 | 查看即将出发的旅行 |

## 6. 旅行结束后的记忆沉淀

```mermaid
flowchart TD
    A[旅行计划] --> B[旅行长卷]
    C[旅行日记与照片] --> D[年度回忆]
    E[旅行花费] --> F[日期档案]
    B --> G[宠物小屋纪念物]
    D --> G
    F --> G
```
