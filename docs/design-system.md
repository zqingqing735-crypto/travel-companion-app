# 设计规范

## 1. 当前视觉方向

当前候选方向为 **旅行手账 × 多巴胺点缀 × 宠物绘本**：

- 70% 温暖纸张、旅行记录和生活感。
- 30% 明亮的粉、黄、薄荷绿和薰衣草紫。
- 宠物、印章、纪念品和小装饰使用手绘风。
- 正文、按钮和数据保持清晰现代，避免整体过度儿童化。

该方向仍处于视觉确认阶段，功能结构已经确定。

## 3. 字体

| 场景 | 字体建议 |
| --- | --- |
| 中文 UI | Noto Sans SC |
| 英文标签与数字 | DM Sans |
| 手账大标题与月份 | Lora |

- 正文建议不小于 14 pt。
- 辅助标签最低 10–11 pt，仅用于非关键信息。
- 长文本保持充足行距，不使用纯手写字体承载正文。

## 4. 形状与质感

- 页面背景使用奶油纸张色，不使用刺眼纯白。
- 卡片圆角以 16–28 pt 为主。
- 便签、照片和本子允许轻微旋转，范围建议在 ±5° 内。
- 胶带、虚线缝边和纸片阴影只作为点缀，不遮挡文字。
- 宠物使用深绿色或深灰轮廓，保证在彩色背景上的可读性。

## 5. 宠物插画

- 十二生肖保持相同头身比例和轮廓粗细。
- 每只宠物至少包含：默认、开心、思考、安慰和旅行五种核心状态。
- 动作轻量：眨眼、摇尾巴、挥手、背包和戴帽子。
- 不使用写实动物，也不照搬现有商业 IP。

## 6. 动效

- 新建旅行：打字机/出纸动画。
- 日历：浅色标记过渡为正式盖章。
- 宠物：待机呼吸、眨眼和点击反馈。
- 照片：轻微摆动或贴入相框。
- 所有动画提供减少动态效果的降级方案。

## 7. 可用性

- 房间物品首次进入时由宠物逐一介绍。
- 后续保留小型文字标签，避免用户只能猜测点击区域。
- 交互热区至少 44 × 44 pt。
- 不仅依赖颜色表达状态，印章状态同时使用轮廓、透明度和文字说明。
